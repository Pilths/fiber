# UI comparison: model x skill

Same one-page brief (`BRIEF.md`: light span view for AABB - BBCC), built four ways:

| Folder | Model | Skill |
|---|---|---|
| `route/` | Opus 5.5 | Route planning page with the 2D route diagram (final theme) |
| `v3/` | Fable 5.1 | Fable Taste look and data strip, V2 ruled structure, no boxes |
| `v2/` | Opus 5.5 | Built from the owner's likes list: Opus Garden base, simple, desktop only |
| `final/` | Opus 5.5 | Rejected by the owner |
| `merged/` | Opus 5.5 | Fable Taste layout + Fable Impeccable theme (proposed UI style) |
| `bakeoff/fable-garden/` | Fable 5.1 | Garden Skills `web-design-engineer` |
| `bakeoff/fable-tastemaker/` | Fable 5.1 | Tastemaker |
| `bakeoff/opus-garden/` | Opus 5.5 | Garden Skills `web-design-engineer` |
| `bakeoff/opus-tastemaker/` | Opus 5.5 | Tastemaker |
| `opus-taste/` | Opus 5.5 | Taste |
| `fable-taste/` | Fable 5.1 | Taste |
| `opus-impeccable/` | Opus 5.5 | Impeccable |
| `fable-impeccable/` | Fable 5.1 | Impeccable |

Open `index.html` (this folder) in Chrome: tabs show all 4 side by side or one at a time. Works from a downloaded zip, no server needed. `shots/` holds desktop (1440), tablet (768) and mobile (390) screenshots. Sample data only; customer names stay in brackets.

The chosen direction becomes the style for the real UI.
