# Design: Fiber span view (survey-sheet world)

Mode: Operate. Light theme. World lends type, palette, density and one move; controls and navigation stay standard.
- Palette (restrained, cool): sheet #e9eeee, paper #fff, ink #12262e, navy shell #17323f, survey blue #0b5a8a (Available, Chosen, primary action), amber #8a4a0a (Requested), red #a8281c (Faulty), hatch grey (In use).
- Type: Atkinson Hyperlegible Next (UI, tabular numerals), Barlow Condensed (span names, numbers).
- Signature: the core grid is a map sheet: neatline double rule, column ticks 1-12, tube rows as latitude labels, a boxed legend. Status = symbol + pattern + word per cell (ring, half ring dashed, filled square, hatched triangle, cross, tick).
- Layout: span list | span + grid + holds | Reserve + approvals (sticky). 1180: spans drop below. 900: single column, sticky Reserve bar. 390: 12 cells per row, in-cell word hidden, legend carries words.
